# Projeto de Modelagem Estatística: preço de imóveis em Ames (EUA)

Análise estatística do dataset Ames Housing (vendas de casas entre 2006 e 2010), com análise descritiva, testes de hipóteses, intervalos de confiança e regressão linear, além de um dashboard interativo.

## Arquivos

| Arquivo | Conteúdo |
|---|---|
| `app.ipynb` | Notebook com todo o processo de análise |
| `dashboard.py` | Dashboard interativo (Streamlit) |
| `AmesHousing.csv` | Dados originais |
| `dados_tratados.csv` | Dados tratados, gerados pelo notebook e usados pelo dashboard |
| `Requiriments.txt` | Bibliotecas necessárias |

## Como executar

```bash
pip install -r Requiriments.txt
streamlit run dashboard.py
```
